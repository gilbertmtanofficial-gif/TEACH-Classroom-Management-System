TEACH: Local-First Classroom Management System

Problem Statement

In many educational environments, unreliable or non-existent internet connectivity severely limits the effectiveness of digital learning tools and classroom management applications. Teachers often struggle with real-time data entry, behavior tracking, and access to student records when an internet connection cannot be guaranteed. This digital divide hinders efficient classroom operations and equitable access to modern educational resources.

My Role & Work

  • Sole Full-Stack Developer: Independently designed, developed, tested, and deployed the TEACH application from concept to implementation.
  • Project Planning & System Design: Defined the project goals, core features, user workflows, and overall system architecture based on the need for a reliable classroom management tool.
  • Local-First Architecture: Designed the application to support reliable use even when internet connectivity is limited or unavailable, helping teachers continue classroom tasks without disruption.
  • Front-End Development: Built the user interface with a focus on simplicity, responsiveness, and ease of use for teachers managing classroom records and student information.
  • Back-End Development: Developed the server-side functionality needed to handle application data, support user interactions, and manage communication between the client and server.
  • Data Management: Implemented structured data handling for classroom records, student information, behavior tracking, and other teaching-related features.
  • Testing & Debugging: Tested the application across different scenarios, identified issues, and resolved bugs related to functionality, deployment, service workers, caching, and user experience.
  • Deployment & Maintenance: Deployed the application to Heroku, configured the project for public access, and continued refining the system based on testing results and technical requirements.
  • Documentation & Portfolio Integration: Prepared supporting materials including screenshots, project descriptions, technical explanations, and portfolio content to clearly present the purpose and impact of TEACH.

Solution: TEACH - Empowering Educators, Locally.

TEACH (Teachers' Educational Assistant for Classroom Harmony) is an innovative classroom management system designed with a **local-first approach**. It prioritizes offline functionality, allowing teachers to manage student behavior, track progress, and record data even without an active internet connection. Data is stored robustly on the local device using IndexedDB and intelligently synchronizes with a central server (or other peer devices) when connectivity is restored, minimizing disruption and ensuring data integrity. This makes TEACH an ideal solution for schools in remote areas or those with intermittent internet access.

Key Features

  • **Offline-First Data Entry:** Seamlessly record student behavior, attendance, and notes without an internet connection.
  • **Real-time Local Sync:** Instantaneous updates across all teacher devices within the same local network via WebSockets.
  • **Student Behavior Management:** Customizable behavior tracking and reporting tools.
  • **Class Records & Analytics:** Centralized system for grades, assignments, and student performance insights.
  • **User Authentication:** Secure login and role-based access for teachers and administrators.
  • **Responsive User Interface:** Accessible and functional on various devices (desktops, tablets).

Technologies Used

  • **Frontend:** JavaScript, TypeScript, React.js, HTML5, CSS3
  • **Backend:** Node.js, Express.js
  • **Database:** IndexedDB (Client-side), [PostgreSQL]
  • **Real-time Communication:** WebSockets
  • **Version Control:** Git, GitHub
  • **Deployment:** Heroku
  • **Other Tools:** npm, Webpack, Babel

Challenges & Learnings

  • **Complex Data Synchronization:** Overcoming the intricacies of managing eventual consistency and conflict resolution in a local-first, offline-capable application was a significant challenge. I learned to implement robust versioning strategies and sophisticated merge algorithms.
  • **Real-time Offline Communication:** Designing a WebSocket-based system that functions effectively on a local network without relying on external servers for peer discovery proved challenging. This pushed me to explore mDNS and other local network discovery protocols.
  • **Performance Optimization for IndexedDB:** Handling large datasets efficiently within the browser's IndexedDB required careful schema design and index optimization to ensure a smooth user experience.
  • **Deployment and Scalability:** Configuring a multi-service application (frontend, backend, potentially a separate WebSocket server) for deployment on platforms like Heroku presented learning opportunities in service orchestration and environment configuration.

Outcomes & Impact

  • **Enhanced Classroom Efficiency:** TEACH empowers teachers to maintain seamless operations regardless of internet availability, saving significant time on administrative tasks.
  • **Improved Data Accuracy:** Local-first design minimizes data loss and ensures consistency, leading to more reliable student records.
  • **Accessibility in Underserved Areas:** Provides a viable digital solution for schools and educators in regions with limited or no internet infrastructure.

TEACH Screenshots & Feature Demonstrations

The following screenshots demonstrate the main features of TEACH, including user authentication, classroom setup, student roster management, behavior tracking, learning materials, classroom tools, casting features, and report generation.

Login and Registration

This screen allows users to log in or register for an account before accessing the TEACH platform. It provides the starting point for secure access to the classroom management system.

Homepage

The homepage appears after a successful login and serves as the main dashboard where teachers can access classroom tools, records, learning materials, and other TEACH features.

Class Record & Roster

This feature allows teachers to create classes, add students, and manage class rosters. It helps organize learners by class and supports structured classroom record keeping.

Selecting Class

This screen shows that a class has been successfully created and can be selected. It confirms that the class roster is available and ready for classroom activities and record management.

Behavior Management

The behavior management feature allows teachers to add or deduct points from students based on classroom behavior. It also includes options such as silence and restore to support classroom discipline and participation tracking.

Library

The library allows teachers to upload PDFs and other learning materials. This gives teachers a central place to store instructional resources for classroom use.

Name Picker

The name picker randomly selects students from the class roster. This can be used for recitation, participation, activities, or group classroom engagement.

Timer

The timer helps teachers manage classroom activities by setting a specific amount of time for tasks, exercises, discussions, or assessments.

Countdown Timer

The countdown timer provides a visual animated timer that can be used during classroom activities. It helps students stay aware of the remaining time for a task.

Active Library

The active library displays the available uploaded materials that teachers can access and use during lessons. It shows which resources are ready for classroom presentation or distribution.

Casting

The casting feature allows teachers to present files and online videos for classroom viewing. This supports digital instruction by making learning materials easier to share with students.

Report CSV

The report CSV feature generates reports for student grades, scores, and class records. This helps teachers organize academic performance data for each student and their respective classes.
