TEACH: Classroom Management System

A local-first classroom management platform designed to help teachers manage behavior, class records, student information, and classroom activities even when internet access is unreliable.

Watch Demo View Screenshots View GitHub Repo

Project Overview

TEACH was developed as a capstone project focused on solving classroom management challenges caused by unstable internet connectivity. The system emphasizes availability, usability, and practical classroom workflows.

Problem Statement

Many classrooms experience unreliable internet connectivity, making cloud-dependent tools difficult to use consistently. Teachers often struggle with real-time data entry, behavior tracking, and access to student records when an internet connection cannot be guaranteed. TEACH addresses this issue by supporting local-first access and dependable classroom data management.

Solution

TEACH provides a classroom management platform that supports essential teaching workflows such as class roster management, behavior tracking, learning material access, student ranking, casting, and classroom activity tools. Its local-first design helps teachers continue using the system even when internet access is unreliable.
